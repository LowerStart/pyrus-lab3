Согласование документов и заявок в одной системе

Pyrus — low-code платформа, объединяющая рабочий чат, задачи со сроками и ответственными, согласование документов, Service Desk и CRM. Процессы настраиваются без программистов.

Коротко о платформе

  • Развёртывание: облако или серверы клиента (on-premise)
  • Тариф: есть бесплатный, без ограничения числа пользователей
  • Интеграции: более 50, открытый API и боты
  • Соответствие: реестр отечественного ПО, 152-ФЗ

Возможности

Основные сценарии, для которых компании используют платформу.

Задачи и коммуникации

Задача — это рабочий чат со сроком и ответственным. Обсуждение, файлы и решения хранятся в одном месте, любое сообщение находится поиском.

Согласование документов

Формы и маршруты согласования настраиваются в визуальном конструкторе. История действий и аудит сохраняются в карточке.

Service Desk и CRM

Обращения из почты, мессенджеров и форм собираются в единой системе. Заявки распределяются по маршрутам автоматически.

ЭДО и HR-процессы

Работа с документами и кадровые сценарии (найм, заявки сотрудников) на той же платформе без отдельных систем.

Интеграции и API

Каталог интеграций, открытый API и боты для связи с учётными системами, телефонией и мессенджерами.

Мобильный доступ

Приложения для iOS и Android, веб-версия. Согласовывать и отвечать на задачи можно с телефона.

Частые вопросы

 

Нужны ли программисты для настройки?

Нет. Платформа позиционируется как low-code: формы и маршруты настраиваются в конструкторе.

Можно ли установить систему на собственные серверы?

Да, такой вариант есть на корпоративном тарифе (on-premise).

Нужно ли платить за внешних участников, например поставщиков?

По данным официальной страницы тарифов, платить нужно только за пользователей своей компании. Приглашённые клиенты и поставщики оплачивают свой доступ сами.

Что происходит с данными при остановке оплаты?

По данным справочного центра Pyrus, данные сохраняются, а ранее созданные задачи доступны в режиме чтения.
